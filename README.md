# 🚀 نظام أنتيجرافيتي للإرسال الجماعي المتطور | Antigravity Bulk Mailer

نظام ويب متكامل واحترافي مصمم خصيصاً لإدارة وإطلاق الحملات البريدية الجماعية وتخصيص محتواها بشكل ديناميكي (Personalization) مع تتبع فوري وحي لعملية الإرسال وسرعة التنفيذ. تم بناء الواجهة بجماليات فائقة الحداثة (Premium Dark Glassmorphism) لتحاكي غرف التحكم التقنية المتطورة.

---

## ✨ المميزات الرئيسية للمنظومة

1. **دعم التخصيص الديناميكي المتناهي**: 
   - إمكانية دمج متغيرات مثل اسم العميل، بريده، شركته، أو أي أعمدة إضافية يتم استيرادها من ملف الـ CSV تلقائياً في موضوع ونص الرسالة البريدية عبر الرمز التعبيري الذكي `{{name}}` أو `{{email}}`.
2. **مستورد وقارئ ملفات CSV ذكي**: 
   - اسحب وأسقط أي ملف CSV، وسيقوم النظام فوراً بمعالجته وعرض البيانات في جدول تفاعلي أنيق يشبه جداول البيانات الاحترافية مع توضيح الإيميلات الصالحة والتالفة بدقة.
3. **محرر ذكي ومعاينة فورية تفاعلية**:
   - محرر بريدي يدعم صياغة نصوص عادية أو أكواد HTML كاملة.
   - **شاشة المعاينة الفورية**: عند النقر على أي صف مستلم في الجدول، تتغير معاينة الإيميل أمامك فوراً بالبيانات الحقيقية لهذا المستلم لنفس المعيار قبل الإرسال الفعلي!
4. **مراقبة فاعلة وفورية (Real-time SSE Dashboard)**:
   - بث مباشر عبر الـ Server-Sent Events لمراحل الإرسال (عدد الناجح، الفاشل، النسبة المئوية لإكمال الحملة).
   - توفير شريط تقدم ومؤشر نبضات ضوئي تفاعلي.
   - **سجل العمليات المباشر (Terminal Logs)**: منفذ برمجيات شبيه بالـ Terminal يطبع تقرير الإرسال اللحظي لكل بريد إلكتروني مع تفاصيل الأخطاء في حال فشل الإرسال.
5. **مستويات تحكم كاملة**:
   - إطلاق الحملة، تعليقها مؤقتاً (Pause)، استئنافها (Resume)، أو إلغاء الحملة بالكامل (Stop).
6. **متحكم الفاصل الزمني لحماية الـ SMTP**:
   - شريط تحكم لتحديد عدد الثواني الفاصلة بين كل إرسال (من 1 إلى 15 ثانية) لمحاكاة الإرسال البشري وحماية نطاقك وبريدك من التصنيف كـ (Spam).
7. **فاحص اتصالات SMTP فوري**:
   - زر مخصص لتجربة صحة بيانات خادم الإرسال والتحقق من الربط بنجاح قبل بدء الإرسال الفعلي، لتفادي إهدار موارد الحملة.
8. **حفظ التكوين التلقائي**:
   - يتم حفظ إعدادات الـ SMTP بأمان محلياً في ملف `config.json` تفادياً لإعادة كتابتها مع كل عملية تشغيل.

## 🚀 طريقة التشغيل والتهيئة المحلية

اتبع الخطوات البسيطة التالية لبدء تشغيل النظام على جهازك:

### 1. تثبيت الحزم المطلوبة
لقد قمنا بتثبيت الحزم لك مسبقاً، ولكن إذا قمت بنقل المشروع، يمكنك دائماً تشغيل:
```bash
npm install
```

### 2. بدء مخدم الويب
لتشغيل النظام على جهازك، قم بتشغيل الأمر التالي في جهازك:
```bash
npm start
```
*سيقوم الخادم بالعمل فوراً على المنفذ `3000`.*

### 3. زيارة لوحة التحكم
افتح متصفح الويب الخاص بك واذهب إلى الرابط التالي:
👉 **[http://localhost:3000](http://localhost:3000)**

## 🔒 دليل إعداد SMTP لخدمة Gmail (هام جداً)

لحماية أمان حسابك، لا تسمح شركة Google ومزودو الخدمة الآخرون بتسجيل الدخول باستخدام كلمة مرور حسابك الأساسية عند استخدام نصوص برمجية خارجية. إليك طريقة إعداد بريد Gmail بنجاح:

1. تفضل بزيارة صفحة إدارة حساب Google الخاص بك: [My Account](https://myaccount.google.com).
2. فعّل ميزة **"التحقق بخطوتين" (2-Step Verification)** في تبويب الأمان (Security).
3. ابحث عن خيار **"كلمات مرور التطبيقات" (App Passwords)** في مربع البحث العلوي أو تحت إعدادات التحقق بخطوتين.
4. أنشئ كلمة مرور تطبيق جديدة باسم "Antigravity Mailer".
5. سيمنحك النظام رمزاً مكوناً من **16 حرفاً** (مثال: `xxxx xxxx xxxx xxxx`).
6. استخدم البيانات التالية في لوحة تحكم أنتيجرافيتي:
   - **SMTP Host**: `smtp.gmail.com`
   - **SMTP Port**: `587`
   - **الأمان SSL/TLS**: معطّل (حيث أن المنفذ 587 يستخدم STARTTLS تلقائياً).
   - **اسم المستخدم**: بريدك الإلكتروني الكامل على Gmail.
   - **كلمة المرور**: الصق الـ **16 حرفاً** التي حصلت عليها (دون مسافات).

## 💡 نصائح لحملة إرسال ناجحة

- **حماية الـ Spam**: ننصح بوضع فاصل زمني لا يقل عن `3 ثوانٍ` بين كل إرسال للحملات الكبيرة.
- **تخصيص الرسائل**: استخدم المتغيرات بشكل كثيف (مثال: `أهلاً بك يا {{name}}`) لزيادة معدلات فتح الرسائل وثقة مزودي الخدمة في جودة إيميلاتك.
- **تصميم HTML**: يمكنك نسخ ولصق أي قالب بريدي HTML جاهز ومزخرف مباشرة في خانة كتابة المحتوى، وسيتعامل معه النظام بكفاءة مطلقة!
